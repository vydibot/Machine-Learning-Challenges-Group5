╔════════════════════════════════════════════════════════════════════════════════════╗
║ CURRENT ANALYSIS LIMITATIONS:                                                      ║
╚════════════════════════════════════════════════════════════════════════════════════╝

1. DQN DATA LIMITATION (SINGLE SEED):
   ✗ Only 1 DQN run available (seed not varying)
   ✗ No variance analysis across seeds for DQN
   ✗ Cannot compute error bars/confidence intervals for DQN
   ✗ Sample efficiency and stability metrics based on single trajectory
   ✓ PPO has 3 independent seeds → robust statistics

2. DIFFERENT TRAINING BUDGETS:
   ✗ DQN: 2M environment steps
   ✓ PPO: ~5M environment steps (2.5x longer training)
   → Performance comparison not entirely fair due to different training times
   → PPO has more experience with the environment

3. TRAINING SETUP DIFFERENCES:
   ✗ DQN: Off-policy, experience replay buffer
   ✓ PPO: On-policy, trajectory rollouts with GAE
   → Different algorithms inherently have different learning dynamics
